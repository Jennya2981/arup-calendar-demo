# Календарь задач — публичный образец

Пустой демонстрационный образец веб-приложения «Календарь задач» для клиентов.
Чистый HTML/CSS/JS без сборки и бэкенда. Открыть можно двойным кликом по `index.html`
или через локальный сервер (`npx serve .`).

**Демо:** https://jennya2981.github.io/arup-calendar-demo/

## Что внутри

- `calendar.json` содержит **пустой календарь**: нет задач, нет ответственных, нет пользователей.
- Экрана регистрации и входа нет — календарь открывается сразу.
- Реальных данных и имён в репозитории нет.
- Рабочий календарь команды живёт в отдельном приватном репозитории.

## Как подключить свои данные

1. Создайте репозиторий для данных и положите в него `calendar.json`
   (структура: `version`, `exportedAt`, `people`, `tasks`, `priorities`, `statuses`, `users`).
2. В `js/config.js` укажите свои `owner`, `repo`, `branch`, `file`:
   ```js
   window.CAL_CONFIG = {
     shared: true,
     owner: 'ВашЛогин',
     repo: 'ваш-репозиторий-данных',
     branch: 'main',
     file: 'calendar.json',
     pollMs: 20000
   };
   ```
3. Для записи создайте fine-grained токен с правом **Contents: Read and write**
   только на этот репозиторий и введите его в приложении кнопкой «Войти как администратор».
   Токен хранится только в вашем браузере.

Если `shared: false`, приложение работает автономно: данные лежат в `localStorage`
браузера по ключу `task-calendar.<repo>.v1`, перенос — через «Экспорт/Импорт JSON».

## Возможности

- Виды: день, неделя, месяц, список; часовая сетка 00:00–23:00.
- Задачи: дата, время, ответственный, событие, статус, описание, история переносов.
- Повторение: ежедневно, по будням, еженедельно, ежемесячно, ежегодно.
- Статусы «Отмена» и «Перенос» с датой/временем переноса и историей изменений.
- Фильтры, поиск, статистика, уведомления.
- Перетаскивание задач мышью (только для администратора).
- Экспорт/импорт JSON, светлая и тёмная тема.

## Структура

```
index.html          разметка приложения
css/styles.css      стили
js/config.js        репозиторий и файл с данными, период опроса
js/db.js            чтение/запись calendar.json через GitHub API
js/store.js         состояние, даты, локальное хранение, CRUD
js/ui.js            отрисовка видов
js/modal.js         окна задачи, справочников, входа и уведомлений
js/dnd.js           перетаскивание
js/app.js           инициализация и события
calendar.json       пустой демонстрационный календарь
```
